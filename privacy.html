隐私政策

最后更新：2026 年 9 月

一、核心承诺

你的视频不会离开你的设备。本工具的所有视频处理（人脸检测、打码、编码） 均在访问者的浏览器中于本地完成，不会上传、存储或传输到任何服务器。

二、我们收集哪些信息

本工具本身不收集任何个人信息，包括但不限于：

  • 不收集你上传的视频与图片内容
  • 不收集姓名、邮箱、电话等身份信息
  • 不要求注册或登录
  • 不设置用于追踪的 Cookie（第三方广告可能有独立的 Cookie，见下条）

三、第三方广告

本站可能展示第三方广告（如 Google AdSense）。这些广告服务商可能会：

  • 使用 Cookie 或类似技术，根据你访问过的网站展示个性化广告
  • 收集你的 IP 地址、浏览器类型、访问时间等技术信息

Google 作为第三方广告服务商，会使用 Cookie 在本站投放广告。 你可以访问 Google 广告设置 管理个性化广告偏好，或访问 aboutads.info 了解退出方式。

四、Cookie 说明

本站自身不使用 Cookie。若你看到 Cookie 相关提示，均来自第三方广告服务商。 你可以在浏览器设置中禁用 Cookie，这不影响本工具的核心功能使用。

五、日志与统计

当本站托管于 GitHub Pages 时，GitHub 可能记录访问日志（IP、访问时间等）， 具体请参阅 GitHub 隐私声明。 本站自身不额外收集访问日志。

六、儿童隐私

本工具面向一般用户，不针对 13 岁以下儿童设计，也不会有意收集儿童的个人信息。

七、政策更新

本隐私政策可能会更新。更新后我们会在本页面标注新的生效日期。继续使用本站即视为接受更新后的政策。

八、联系方式

如对本隐私政策有疑问，可通过 GitHub 仓库提交 Issue 联系： github.com/haixiansheng/face-mosaic/issues
